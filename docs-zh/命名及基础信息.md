# RarZap
读音：/rɑːr zæp/（“拉尔-扎普”）

寓意：Zap 有“快速消灭、电击、瞬间转换”的意思。RarZap 读起来像“把 RAR 啪一下变成 ZIP”，动作感强，短促有力，两秒就能记住。

优点：

只有两个音节，拼写简单，不会打错

首字母 RZ 在图标设计上有辨识度（可以做成闪电 + 拉链的组合）

作为应用名、crate 名、域名都干净：rarzap、rarzap.app

适合：想要一个有个性、不呆板、带点俏皮感的名字。

核心关键字：rar to zip

# GitHub Actions自动构建注意事项

1. 图标准确，包括软体窗口左上叫的图标，任务栏的图标，安装过程中的图标，安装包的图标。切记，ai经常忽视的地方。
2. 注意mac端，双击安装包后的窗口，既要有本应用的图标，也要有app的图标，不然不好拖拉。切记，ai经常犯错的地方。
3. 注意检查选择文件的按钮在mac端不可用的情况。切记，ai经常犯错的地方。

# 需要配置的 Secrets: 别的项目用过，复用这些，已配置到github后台

在 GitHub 仓库 **Settings → Secrets and variables → Actions → New repository secret** 添加：

| Secret | 说明 | 来源 |
|---|---|---|
| `MACOS_SIGN_IDENTITY` | 签名身份字符串，形如 `Developer ID Application: Your Name (AB12CD34EF)` | 步骤 2 |
| `MACOS_P12_B64` | 导出证书 `.p12` 的 base64 | 步骤 3 |
| `MACOS_P12_PASSWORD` | 导出 `.p12` 时设置的密码 | 步骤 3 |
| `APPLE_API_KEY_ID` | App Store Connect API Key 的 Key ID | 步骤 4 |
| `APPLE_API_ISSUER` | Issuer ID | 步骤 4 |
| `APPLE_API_KEY_B64` | API Key `.p8` 的 base64 | 步骤 4 |

> 全部配齐才会走「签名 + 公证」；缺任一则会跳过对应环节。证书密码等**只放 Secrets，切勿提交到仓库**。
